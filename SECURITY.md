# Security policy

Please report vulnerabilities privately, not in a public issue. Use GitHub's
**Report a vulnerability** button on this repository's **Security** tab
(private vulnerability reporting).

Include the version, what an attacker can do, and steps to reproduce. You will
get a reply within a week. Please give us a reasonable time to ship a fix
before you disclose details.

Only the latest release is supported with security fixes.

Things worth reporting: anything that lets one viewer read or change another
viewer's data, a way past Jellyfin's sign-in or administrator checks, ways to
forge or replay companion bridge requests, leaks of API keys or secrets, and
requests to hosts the operator did not configure.
